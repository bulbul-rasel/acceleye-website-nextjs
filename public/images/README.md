# Images

    photos/            real photographs. Name each file after its slot: roleTeacher.jpg, library.webp ...
    illustrations/     generated illustrations for slots without people (npm run illustrations)

Every slot, what to put there and where it appears is listed in the running site at /image-slots,
and in src/content/imageSlots.ts. Until a photo exists the slot shows a "Photo needed" box.
A photo with the same name as an illustration replaces it.
